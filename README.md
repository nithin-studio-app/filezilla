# file-manager

Published for consumption by `my-apps-setup`. `react`/`react-dom` are peer
dependencies — never bundled — so the host resolves a single shared copy.

## Develop

Point `my-apps-setup` at this repo's local `src` via its `LOCAL_*` alias env
var (see its `vite.config.ts`) to get live reload without publishing.

## Build

```bash
pnpm build
```
